## 二、按里程碑分组

| 里程碑（WBS） | 原型页面 |
|---|---|
| M1 范围与契约 | 无独立页面；契约状态落在「计费报文监控」「审批中心」 |
| M2 PQM 底座与基础数据 | 工作台、费用项、产品、客户、角色、日志 |
| M3 计重规则与产品价格 | 价格模版、分区、杂费、仓点、底价、公布价、套餐、批量调价、版本 |
| M4 客户价格与计价 | 客户绑定、自由价、取价优先级、AI 配置、计重规则、计重解析 |
| M5 线上询价与订单报价 | 询价列表/新建/详情、路由时效、订单绑定 |
| M6 试算与报价单 | 内部试算、报价单模板/资料/列表/预览 |
| M7 计费与财务链路 | 计费列表/详情、改价勘误、报文监控 |
| M8 验收与切换 | 无独立页面；在「报文监控」展示旧契约兼容/切换状态，在 README 记录验收口径 |

## 三、演示主链路

1. **主数据**：费用项 → 产品映射 → 客户归属。
2. **产品价格**：底价（OA）→ 公布价 A（校验 > 底价）→ 套餐 B–E → 批量调价预览。
3. **客户价格**：绑定套餐 / 自由价（低于底价转审批）→ 取价优先级查询。
4. **询价**：新建（AI 识别）→ 纵队录成本 → 港前确认 + 附加费 → 销售报价 → 绑定订单形成订单价。
5. **试算/报价单**：内部试算命中客户套餐 → 生成客户报价单 → 发布用户中心 → 企微发送。
6. **计费**：签入报文 → 计费单 → 计费明细/重算 → 改价或勘误 → 回传 CCOS/OMS/ARS。

## 四、边界说明

- 原型是**交互与信息架构演示**，数据均为示例；接口字段、状态机以 WBS 与后续契约评审为准。
- 以后端为主的包（服务底座、鉴权幂等、接口契约、数据迁移、联调验收）不画操作页，转为页面上的状态、错误提示、报文日志和审批留痕。
- X 系列、整柜的首期定价范围、询价是否不限产品、费用项规则专项、年底切换时点等业务口径仍待确认，页面中以「待确认」标注，不写成既定规则。
